# 📨 Newsletter Sign-up Form with Success Message – Frontend Mentor Challenge

### 📌 About the Project

This project is a **newsletter sign-up form with a success state**, developed as part of a **Frontend Mentor** challenge.  
The main objective was to recreate the provided design and implement form submission flow, including validation and navigation to a success page.
The application was built using **React.js** for component logic, **Vite** for a fast development environment, **Tailwind CSS** for utility-first styling, **React Hook Form** for form state management, and **React Router DOM** for client-side navigation.

### 🛠️ Technologies Used

[![My Skills](https://skillicons.dev/icons?i=react,vite,tailwind,html,js)](https://skillicons.dev)

### 🧠 Learnings

During the development of this project, it was possible to:

- Practice **form handling and validation** using React Hook Form.
- Implement **multi-page flow** with React Router DOM.
- Work with controlled navigation between form and success states.
- Improve form performance and code organization.
- Build responsive UI layouts using **Tailwind CSS**.
- Enhance development workflow with **Vite**.
